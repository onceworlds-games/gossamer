# Red Light Green Light

Run toward the finish while the light is green, freeze when it turns red. Get caught moving and it's back to the start.
Up to 12 players, bots fill the table to 8. Hold Space (or the Run button, or a finger on the right half of the screen) to run,
let go on yellow, steer with A D / arrows or the thumbstick.

Play it at https://onceworlds.com/play/red-light-green-light

Plain ES modules and Canvas 2D, no build. `npm test` runs the rules, the bots and a full bot-only match.
